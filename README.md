# Reactiongame
a C# game for a school project

Esittely suomeksi
yksinkertainen peli, joka testaa montako kertaa pelaaja ehtii reagoida ajoissa, kun näytölle ilmestyy kuvia.
ohjelma tallentaa pelaajan nimen pisteet ja hudit listaan ja näyttää 10 eniten saanutta.
kehitys listaan olisi: pisteistä karsitaan miinukset pois, ennen kuin ne kirjoitetaan ruudulle, pistetaulukosta luettaviksi.


Aloitus näkymä. pelaajan nimen voi antaa halutessa oikeaan yläkulmaan

Peli käynnissä. paina näppäimistön nappeja heti, kun ne ilmestyvät näytölle.
![alt text](<Reaction game SC 2.png>)

Peli loppu. tulos tallennetaan listaan. listan tallennus paikka näytetään omassa ikkunassa.
![alt text](<Reaction game SC 3.png>)


Pelaajan nimen ja pisteiden olemassaolon julistus.
![alt text](<Reaction game SC 4.png>)

Klikkaus rekisteri. tarkista osuiko painallus oikeaan aikaan.
